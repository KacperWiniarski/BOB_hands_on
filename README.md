# Witamy na warsztatach z IBM Bob! 🤖

Celem warsztatów jest przygotowanie agenta AI do oceny spółek.

## Repozytorium

https://github.com/KacperWiniarski/BOB_hands_on.git

## Struktura warsztatów

Warsztaty podzielone są na 5 zadań, z których każde znajduje się w osobnym folderze:

- `task1/` - Zadanie 1
- `task2/` - Zadanie 2
- `task3/` - Zadanie 3
- `task4/` - Zadanie 4
- `task5/` - Zadanie 5

## Wymagania

Sprawdź plik `requirements.txt` aby zainstalować niezbędne zależności:

```bash
pip install -r requirements.txt
```

## Konfiguracja

Skopiuj plik `.env.example` do `.env` i uzupełnij wymagane zmienne środowiskowe.

Powodzenia na warsztatach! 🚀
